# Пустые: тренажёр ума

Офлайн-PWA для ежедневной тренировки памяти, логики и концентрации. Один подход — 1–3 минуты.

Игры:
- 🔢 **Память на цифры**: запомни ряд и повтори, длина растёт.
- 🎯 **Таблица Шульте**: найди числа 1–25 по порядку на время.
- ➕ **Устный счёт**: 60 секунд примеров, сложность растёт.
- 🧩 **Закономерности**: продолжи числовой ряд, 10 вопросов.
- 🟦 **Память позиций**: запомни подсвеченные клетки.

Рекорды, серия дней и счётчик игр хранятся локально в браузере.

## Как запустить
Открыть `index.html` в браузере. Чтобы установить на телефон как приложение,
включите GitHub Pages (Settings → Pages → Deploy from branch → `main` / root),
откройте адрес сайта и выберите «Добавить на главный экран».
